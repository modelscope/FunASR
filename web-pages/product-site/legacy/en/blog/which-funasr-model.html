Choosing a FunASR model starts with the result you need

Published 2026-06-23 · Revised 2026-11-19 · Beginner selection guide

You want to turn an interview into subtitles. Your search brings up FunASR, Fun-ASR, SenseVoice, Paraformer and FunClip, followed by PyTorch, ONNX and vLLM. Which one should you install? These names describe different layers: a toolkit, models, runtimes and an application. They are not interchangeable alternatives.

This article requires no installation. Its deliverable is a selection brief: what audio goes in, what result must come out, which processing path to try, and what remains to be verified. Define that task before following an installation guide.

1. A transcript is not automatically a subtitle file

Imagine an interviewee says, “Send three samples next Wednesday.” Recognizing those words completes the automatic speech recognition (ASR) step. Subtitles also need start and end times. A conversation may need segments assigned to different speakers. A nonempty transcript does not establish either capability.

  • Text: what was said, suitable for searching and editing.
  • Timestamps: where words or segments occur in the recording. Character, word and segment timing have different granularity.
  • Speaker labels: which segments may belong to the same speaker. Speaker 0 is not a person's name and is not necessarily the same person in another recording.
  • Streaming results: partial text returned while audio is still arriving. File transcription support does not establish an equivalent streaming interface.

Two other components often cause confusion. Voice activity detection (VAD) locates speech regions; it does not transcribe each word. A punctuation model helps divide text into sentences; a full stop is not a subtitle timestamp. Identify the required outputs before adding every available component.

2. Four projects, different responsibilities

NameWhat it isWhen to start here
FunASRA speech toolkit with runtime and service code. Its Python package is named funasr.Combine recognition, VAD, punctuation or speaker processing in your program, or find a deployment entry point.
Fun-ASRA model family and model-side integrations. Nano and MLT-Nano are separate checkpoints: model weights and companion files that must be selected separately.Check their language scope, weight formats and matching inference interfaces.
SenseVoiceA speech understanding model family. This article discusses SenseVoiceSmall specifically.Consider transcription plus its language, emotion and audio-event tags.
FunClipAn application for audiovisual transcription, subtitles and clipping.Start with a clipping workflow rather than build the whole interface yourself.

pip install funasr installs software, not every model's weights. Weights contain the parameters learned by a model. A runtime loads those files and performs computation. Different weight formats may represent related models, but they are not freely interchangeable. An HTTP service adds another layer to receive requests, invoke inference and return results.

Connecting an application to an existing speech API is therefore different from installing a model locally. A remote service may upload audio and incur charges. Local execution usually requires downloading software and weights first. The toolkit's MIT licence does not automatically apply to every model's weights, dataset or external service.

3. Answer four questions before choosing

Which languages are actually in the audio?

“Chinese” or “multilingual” is not specific enough. Mandarin, Cantonese, Japanese, and Mandarin mixed with English product names are different test conditions. Check the specific checkpoint's language documentation, then evaluate representative audio. A listed language does not prove that your accents, noise conditions or specialist terms have been tested.

Do you need text, subtitles or edited clips?

For text alone, begin with a simple file-transcription path. For subtitles, check whether the chosen model and interface return the required timing granularity and how to export the result. Clipping one person's contributions also requires speaker processing and application-level selection. Do not distribute missing timestamps evenly across words and present them as model alignment.

Will you process a finished recording or display words as people speak?

“Offline file recognition” often means processing a complete recording; it does not guarantee that execution never contacts the network. Network-isolated operation requires prepared dependencies, weights, configuration and related resources, followed by an actual isolation test. Live captions need a streaming checkpoint or a service explicitly supporting that workflow, including partial results, end signals and session state.

What do your machine and data permissions allow?

Record the operating system, available RAM and CPU, plus GPU model and memory if present. Loading a model on CPU does not prove realtime performance. Owning a GPU does not mean the software is configured to use it. Establish whether audio may leave the machine, whether weight downloads are authorized, and whether the intended use meets the model's terms. These constraints can eliminate unsuitable paths early.

4. Useful candidates, not a universal ranking

Mandarin files, timestamps or hotwords: inspect the Paraformer path

Paraformer is a family, not a single switch covering every interface. FunASR documents a Mandarin-oriented paraformer-zh path and timestamp and hotword usage. Check those features against the exact package, model and service you plan to use. The streaming path uses the separate paraformer-zh-streaming checkpoint; an offline model name is not a substitute.

Transcription with sound-related tags: inspect SenseVoiceSmall

The official documentation lists Mandarin, English, Cantonese, Japanese and Korean for SenseVoiceSmall, alongside emotion and audio-event tags. This is not a promise of arbitrary language support. An emotion tag is a model prediction, not a determination of someone's true psychological state, and it is not a speaker identity.

In the SenseVoiceSmall + FSMN-VAD + CAM++ combination, VAD locates speech regions, CAM++ extracts speaker features, and the FunASR pipeline clusters them into anonymous labels. Several components work together; SenseVoiceSmall does not provide all those capabilities alone. When raw sound-related tags matter, also check whether postprocessing or the service removes them.

Evaluating Fun-ASR: choose the checkpoint before the loader

Base Fun-ASR-Nano and the 31-language Fun-ASR-MLT-Nano are different checkpoints. Base Nano's documentation covers Chinese, English and Japanese, plus the documented Chinese dialects and regional accents. Do not transfer MLT-Nano's language scope to base Nano.

Distinguish original FunASR weights, the native Transformers -hf export, GGUF files and native vLLM artifacts. CPU, CUDA, native Transformers and vLLM paths have their own loading and dependency requirements. Changing one model string does not establish a successful migration, and measurements or features from one path do not automatically carry over to another.

Working with video: start from the FunClip application workflow

If the deliverable is subtitles or edited clips, inspect the FunClip workflow first, then check the recognition backend it actually uses. Export support at the application level does not mean every backend provides identical timestamps or speaker information. Before enabling external language-model-assisted clipping, establish which data will be sent, which service receives it and whether it charges for usage.

5. Produce a brief that guides the next step

This is a hypothetical task, not a completed inference result: you have permission to process a Mandarin interview, want searchable text first, have only a CPU, and cannot upload the audio to external services.

  • Input: a local Mandarin interview. Begin with an authorized short excerpt containing names, numbers and a sentence ending.
  • First deliverable: a local UTF-8 transcript file. Do not promise subtitle timing or known-person identification at this stage.
  • Candidate: the toolkit's Paraformer Mandarin file-transcription path, using the beginner guide below. This is a candidate, not a proven best model.
  • Allowed operations: download specified software and weights after checking their terms. Do not upload the recording, invoke paid services or overwrite originals.
  • Acceptance: obtain a newly generated result and listen back to verify important content. Record whether local runtime and memory use are acceptable.
  • Next stage: after the short excerpt works, check long-recording coverage. Revisit timing and speaker requirements if subtitles or speaker-based clipping are added.

This is more actionable than “find the strongest model.” If the candidate fails a requirement, retain the failing samples and reasons before comparing another candidate. Do not present only the clips that worked best.

For AI agents: requirements are not API parameters

The brief above describes the task shared by a person and an agent. It is not a FunASR SDK configuration schema. Map it to actual commands or function arguments using the selected version's documentation before execution.

  • Input: record the real audio path, format, channel count, sample rate in Hz and duration in seconds. Inspect unknown values rather than infer them from an extension. Example paths are not existing files.
  • Model: record the full model ID, revision or checksums, weight format, runtime and software versions. A short service alias is not necessarily a downloadable model ID.
  • Output: agree on paths, encoding and required fields. Specify timestamp units and granularity when needed, and recording-local scope for speaker labels. Never invent fields that the backend did not return.
  • Permissions: transcription instructions do not implicitly authorize downloads, external uploads, remote code, paid calls or overwriting results. Stop the relevant operation when permission is missing.
  • Failure: use actual process exit codes or API errors, and never substitute an old output for a new result. Preserve the error; retry only within agreed bounds after addressing its cause. Do not silently switch models, launch parallel copies or fall back to an external service.

6. How do you know the choice fits?

First check that the path completes the task; then compare quality and resource use. Use authorized, representative audio covering clear speech, noise, names, numbers and easily missed endings. For multi-speaker or subtitle tasks, listen back to check turns and timing. One clean sample is a starting point, not a complete quality evaluation.

Compare candidates on the same input with a review method chosen in advance. Fluent text is not necessarily faithful to the recording. A CER/WER figure without its data, normalization rules and evaluation scope is insufficient. Timing measurements should identify hardware and batch settings and separate downloading, loading and recognition time.

This is a selection explainer based on official documentation. It adds no model-inference, accuracy, realtime or capacity measurements. It supplies neither a cross-model performance ranking nor a claim that every linked path was tested in one environment.
