用 Python 把第一段录音转成文字

2026-06-18 发布 · 2026-11-17 重写 · 入门教程

你有一段中文录音，想把里面说的话变成可以搜索、复制的文字。先不用搭服务器，也不用训练模型。这篇教程只做一件事：在自己的电脑上运行 Python，把一段短录音保存为文字结果文件。

我们先用官方示例音频走通流程，产物是 transcript.json。成功后再换成你有权使用的录音。整条路径是：准备 Python 环境 → 安装工具 → 准备音频和模型 → 识别 → 打开结果并回听核对。

本文选择普通话、CPU、单段不超过 30 秒的 WAV。这个时长是教程主动设置的入门范围，不是 FunASR 的统一上限。本例只输出转写文字，不承诺自动生成字幕、识别人名、区分说话人或达到实时速度。

1. 先分清：工具包、模型和应用

语音识别（ASR）就是把声音里的话转换成文字。你需要两样东西：负责加载文件、组织计算的程序，以及已经学过如何识别语音的模型。

  • FunASR是工具包。pip install funasr 安装的是 Python 程序，不是所有语音模型。
  • Paraformer、SenseVoice、Fun-ASR是不同的模型或模型系列。模型权重是另行下载的文件，支持的语言、参数和输出不完全相同。本篇只用 Paraformer 中文路径，不在第一步同时比较多个模型。
  • FunClip是面向音视频转写与剪辑的应用。想直接操作视频剪辑界面，可以从应用入手；想把识别放进自己的程序，则从本篇的 Python 路径入手。

第一次把录音转成文字，不需要先学训练、微调或 GPU 优化。先完成一次小任务，后面再根据字幕、会议记录或实时交互的需求加能力。

2. 开始前准备什么

下面是一条明确的 Linux x86_64、Python 3.11、CPU 安装路径。你需要能打开终端、创建文件夹，以及在首次安装软件和模型时联网。CPU 路径不需要配置 CUDA；运行速度和内存需求取决于模型与机器，不保证实时。

Windows、macOS 或已有 GPU 环境请先走安装指南选择对应的 PyTorch 版本，不要直接把 Linux CPU 命令拼进已有环境。模型下载需要可写缓存和足够磁盘空间；软件安装成功不代表权重已准备好。

3. 建一个独立环境，再安装

独立环境像这个练习自己的工具箱，可以减少与其他项目的依赖冲突。请在终端按顺序运行：

mkdir first-transcript
cd first-transcript
python3.11 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install "torch==2.8.0" "torchaudio==2.8.0" --index-url https://download.pytorch.org/whl/cpu
python -m pip install "funasr==1.4.26"
python -m pip check
python -c "import sys, funasr, torch, torchaudio; from funasr import AutoModel; print(sys.executable); print(funasr.__version__, funasr.__file__); print(torch.__version__, torchaudio.__version__)"
python -m pip freeze > environment.txt

这里固定 FunASR 1.4.26，并按 PyTorch 官方版本页配对 torch/torchaudio 2.8.0。它不是整个依赖树的锁文件，所以保留 environment.txt，以后排错时知道实际安装了什么。版本检查应显示 FunASR 1.4.26，Python 路径应属于刚创建的 .venv；这一步只证明环境能导入，不是识别成功。

4. 先用示例音频，减少变量

下载官方教程引用的中文 WAV。这条命令只下载音频，不会上传你的录音：

curl --fail --location --output sample.wav https://isv-data.oss-cn-hangzhou.aliyuncs.com/ics/MaaS/ASR/test_audio/asr_example_zh.wav

WAV 是音频文件的封装格式；16 kHz 表示每秒 16000 个采样点；单声道表示一条声音通道。本篇脚本只接受单声道、16000 Hz、16 位 PCM WAV。把 MP3 后缀改成 .wav 不会完成格式转换。

换自己的音频时，先选一段有清晰普通话、你有权处理的短录音。若需要转换格式，可以用已安装的 FFmpeg 另存为新文件，保留原始录音：

ffmpeg -n -i my-recording.mp3 -ac 1 -ar 16000 -c:a pcm_s16le my-recording-16k.wav

my-recording.mp3 要替换成实际文件路径；-n 表示已有输出不覆盖。转换整段音频不会自动变短，仍需选取不超过 30 秒的输入。确认声音正常后再交给模型，避免把文件问题误认为识别问题。

5. 运行完整的转写脚本

把下面完整代码放在工作目录的 transcribe_first.py。你暂时不需要理解每一行：前半段检查文件，AutoModel(...) 加载模型，generate(...) 开始识别，最后保存 JSON。输入不合要求时会先停止，不先下载大模型。

import argparse
import json
from pathlib import Path
import wave

MODEL_ID = "iic/speech_seaco_paraformer_large_asr_nat-zh-cn-16k-common-vocab8404-pytorch"


def main(argv=None):
    parser = argparse.ArgumentParser(description="One short Mandarin WAV to one JSON transcript")
    parser.add_argument("--audio", required=True)
    parser.add_argument("--output", default="transcript.json")
    source = parser.add_mutually_exclusive_group(required=True)
    source.add_argument("--model-dir")
    source.add_argument("--allow-download", action="store_true")
    args = parser.parse_args(argv)

    audio = Path(args.audio).expanduser().resolve(strict=True)
    output = Path(args.output).expanduser().resolve()
    if not audio.is_file():
        parser.error("--audio must be a local WAV file")
    if output.exists() or not output.parent.is_dir():
        parser.error("Choose a new output file in an existing directory")
    with wave.open(str(audio), "rb") as wav:
        if (wav.getnchannels(), wav.getsampwidth(), wav.getframerate(), wav.getcomptype()) != (1, 2, 16000, "NONE"):
            parser.error("Expected mono, 16-bit PCM WAV at 16000 Hz")
        frames = wav.getnframes()
        duration = frames / 16000
        if not 0 < duration <= 30:
            parser.error("This first example accepts more than 0 and at most 30 seconds")
        if len(wav.readframes(frames)) != frames * 2:
            parser.error("WAV data is truncated")

    model_source = MODEL_ID
    if args.model_dir:
        directory = Path(args.model_dir).expanduser().resolve(strict=True)
        if not directory.is_dir():
            parser.error("--model-dir must be a complete local model directory")
        model_source = str(directory)

    from funasr import AutoModel, __version__

    model = AutoModel(
        model=model_source, hub="ms", device="cpu", ncpu=4,
        disable_update=True, trust_remote_code=False,
    )
    results = model.generate(input=str(audio), batch_size=1)
    if not isinstance(results, list) or len(results) != 1 or not isinstance(results[0], dict):
        raise RuntimeError("Expected one result dictionary; inspect the model and input")
    text = results[0].get("text")
    if not isinstance(text, str) or not text.strip():
        raise RuntimeError("No non-empty transcript; listen to the input before retrying")
    record = {
        "text": text,
        "audio": str(audio),
        "duration_seconds": duration,
        "model_dir": str(model.model_path),
        "funasr_version": __version__,
    }
    with output.open("x", encoding="utf-8") as target:
        json.dump(record, target, ensure_ascii=False, indent=2)
        target.write("\n")
    print("Wrote:", output)


if __name__ == "__main__":
    main()

首次使用，先阅读所选模型的模型卡和使用条款，确认允许下载与使用后运行：

python transcribe_first.py --audio sample.wav --allow-download --output transcript.json

--allow-download 是本教程脚本的选项，不是 FunASR 通用参数。它允许从 ModelScope 获取上面明确指定的模型。第一次运行包含下载和加载时间，不能把它当成纯识别耗时；脚本没有自动重试，也不会在失败时自行换模型。

6. 怎样判断真的做成了

python -m json.tool transcript.json

先确认上一条转写命令正常退出，而且本次新建的 JSON 文件能被解析。文件里的 text 是识别结果；audio 是输入路径；duration_seconds 的单位是秒；model_dir 是实际加载的模型目录；funasr_version 是运行时版本。

然后回听这段音频，重点核对人名、数字、否定词和句尾。生成文件是程序执行成功，文字与原音频一致才是内容可用。不要因为 JSON 里有非空文字，就把它当作准确答案。这个简单流程没有配置标点模型，也不把返回文字包装成字幕时间轴。

第二次处理自己的录音时，可以复用 JSON 中记录的 model_dir，把它替换到下面的 /absolute/path/to/model。该路径必须是完整、可信的同款模型目录，不是仅有一个权重文件：

python transcribe_first.py --audio my-recording-16k.wav --model-dir /absolute/path/to/model --output my-transcript.json

本地目录可以避免再次按模型 ID 请求下载，但不是自动断网保证。离线部署还要准备齐依赖、模型配置及相关资源，并实际在禁止外联的环境验证。disable_update=True 只关闭 FunASR 版本检查。需要复现同一模型时，记录完整模型 ID、revision 和文件校验值；模型 ID 本身不是不可变版本。

7. 卡住时，从对应的一层查起

现象先做什么
找不到 python3.11 或 venv先安装对应 Python 与 venv 组件，确认解释器可用；不要跳过环境步骤继续装包。
找不到 funasr，或 torch/torchaudio 导入失败重新激活 .venv，检查 python 路径与 python -m pip --version，再核对成对的 PyTorch 构建；不要直接升级全部依赖。
文件不存在、不是 WAV、采样率不符或超过 30 秒核对路径，先播放音频，再转换成要求的格式或选取短片段。脚本不会靠修改采样率标签修复音频。
模型下载失败或长时间无结果查看终端最后的下载/异常信息，检查网络、缓存权限与剩余磁盘；解决原因后再明确重试，不要多开一批相同进程。
内存不足或进程被系统结束先停止重复实例，核对可用内存与模型要求。缩短音频只能减少部分开销，不能消除权重本身的内存需求。
提示已有输出文件检查原结果，给新运行换一个输出文件名。脚本故意不覆盖已有文件。
结果为空或内容不对确认确实有人声、语种为普通话、声道与采样率正确。保留错误和原文，不用预期答案补齐或偷偷换模型。

给 AI Agent 的执行约定

把本篇作为本地文件处理任务，而不是远程语音服务接口。Agent 应先完成权限与文件检查，再执行同一条脚本路径。

  • 输入：--audio 是已授权的本地文件路径，不接受 URL；单声道、PCM16、16000 Hz，时长大于 0 且不超过 30 秒。--output 是现有目录中的新文件路径，默认 transcript.json。
  • 模型选择：--model-dir 与布尔开关 --allow-download 二选一。优先使用用户已准备好的完整同款目录；下载前确认来源、条款、磁盘和网络授权。不要把其他模型目录套进本篇并假定参数与能力相同。
  • 输出：读取 UTF-8 JSON 文件中的 text（字符串）、audio（字符串）、duration_seconds（数字，秒）、model_dir（字符串）、funasr_version（字符串）。标准输出可能混有库日志，不能直接按 JSON 解析。
  • 成功：进程退出码为 0、本次新文件存在且 JSON 可解析、text 非空。随后标记“转写待核对”，不要自动宣称内容正确或生成 speaker/timestamp 等未提供字段。
  • 失败：参数错误退出码为 2；其他异常非 0。停止并保留错误，不把旧文件当新结果，不自动覆盖、重试下载、启用远程代码或改用收费服务。不上传用户音频。

依据与验证范围

API 与模型选择依据 1.4.26 官方教程、模型映射及AutoModel 实现。随文代码的参数、输入检查、调用约定、结果校验和文件保护使用模型替身测试；本次改写没有运行预训练模型识别，也没有验证上述安装组合的端到端识别，不提供准确率、速度或 GPU 测量结论。实际使用需完成第 6 节的首次识别与回听检查。软件许可不替代模型权重各自的条款。

短录音路径完成后，如果你的目标是处理会议或课程录音，接着读长录音怎样切分并检查是否遗漏，再逐步增加复杂度。
