FunASR v1.4.16：混合设备子模型与原生 Transformers 指南

2026-09-18 · FunASR 正式发布

v1.4.16 让显式配置的 VAD、标点和说话人 submodel 在重复推理与运行时覆盖之间保持各自设备，并补齐标点行为和原生 Transformers 接入文档。

安装

python -m pip install -U "funasr==1.4.16"

公开包位于 PyPI 1.4.16。wheel SHA-256 为 f95943f6a8111349a1b08907363b048a49e9cb9caa1e3afd8c92970d08bf450d，sdist SHA-256 为 1e2f8e3887fbc4b164cce40f73bf1324907da6ab59d1e8bf2add827f534c69e7。

这次修复什么

  • vad_kwargs、punc_kwargs 与 spk_kwargs 的显式设备放置在重复调用中保持稳定。
  • 运行时 device 覆盖不再改写已加载模型或调用方持有的子模型配置。
  • 说话人推理使用说话人模型自身配置；中英文指南说明何时需要 CT-Transformer 标点后处理，以及如何验证原生 Transformers 路径。
设备回归由 CPU 权重替身与模拟加速器可用性验证；它覆盖配置传播、回退和重复调用，但不是 CUDA、MPS 或 NPU 性能认证。
