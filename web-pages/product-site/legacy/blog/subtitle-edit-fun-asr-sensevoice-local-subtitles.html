Subtitle Edit 5.2：用 Fun-ASR Nano / SenseVoice 在本地生成视频字幕

2026-08-03 · FunASR 生态集成

Subtitle Edit 是跨平台开源字幕编辑器。它的 v5.2.0-beta2 已包含 Crisp ASR Fun-ASR Nano 和 Crisp ASR SenseVoice 两个本地语音识别引擎，可在 Windows、macOS 与 Linux 里从视频直接生成字幕，再继续校时、断句和导出。

版本说明：当前是 beta 版本，适合先用实际视频验证工作流，再决定是否用于生产。本文只描述 v5.2.0-beta2 exact tag 中可核验的能力。

三步开始本地转写

  1. 安装或解压 Subtitle Edit v5.2.0-beta2，并打开待处理的视频。
  2. 进入 Video → Audio to text。
  3. 在 Engine 中选择 Crisp ASR Fun-ASR Nano 或 Crisp ASR SenseVoice，选择语言和模型精度后开始转写。

整个流程位于 Subtitle Edit 的字幕工作区内，无需把音频上传到云端。生成结果可继续使用 Subtitle Edit 的时间轴、波形、字幕格式与质检能力。

这次 beta 更新核验了什么

Subtitle Edit PR #13063 更新了 CrispASR 运行时，并记录了 SenseVoice 在 Apple Metal 路径上的转写验证。该 PR 还加入了其他引擎；Fun-ASR Nano 和 SenseVoice 后端本身已存在于项目中，因此这里不把 #13063 表述成“首次接入”。

  • Release 提供 Windows、macOS 和 Linux 下载资产。
  • Fun-ASR Nano 与 SenseVoice 的三个模型精度都在 exact tag 源码中列出。
  • 本地工作流把识别、字幕校时、断句和格式导出放在同一个桌面工具里。

先用短视频和目标语言验证时间轴与文本质量，再处理长视频。遇到问题时请同时附上操作系统、引擎、模型精度和可复现片段。
